# 🎃 Halloween

A simple Halloween-themed website featuring spooky images, a mysterious story, and a gallery. Built using HTML and CSS.

## Features

- Halloween-themed homepage
- Spooky image gallery
- A short horror story
- Dark theme with orange accents
- Simple navigation between pages

## Built With

- HTML
- CSS

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/himanshusapkota/-Halloween.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
